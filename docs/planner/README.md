# docs/planner/

**Purpose:** Planner-side operating contract for Plan-Gate-Verify work.

**Data stored here:** Markdown only. These files describe how the planner
frames work, verifies results, and signs off gates.

## Portals

| Portal | File | Type | Holds |
|---|---|---|---|
| `behaviour____` | [behaviour.md](behaviour.md) | Markdown | Planner responsibilities, forbidden actions, verification checklist |

## Rule

The planner writes plans and verifies outcomes. The planner does not write
production code for the same feature it will later sign off.

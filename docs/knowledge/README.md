# docs/knowledge/

**Purpose:** Staging area for reusable knowledge before a standalone
knowledge-capture project exists.

**Data stored here:** Markdown only. Keep entries structured enough that a
future extractor can parse them, but do not treat this folder as the final
knowledge base.

## Portals

| Portal | File | Type | Holds |
|---|---|---|---|
| `candidates____` | [capture-candidates.md](capture-candidates.md) | Markdown | Reusable facts, lessons, shortcuts, and component data waiting for verification |

## Flow

Add a capture candidate when a measurement, Fusion 360 trick, build lesson,
component model, script pattern, or design rule looks reusable. Keep the source
and verification state attached to the candidate. Promote it later only after
the physical project gives enough evidence.

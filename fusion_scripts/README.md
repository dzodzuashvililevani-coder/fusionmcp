# fusion_scripts/

**Purpose:** Python that runs **inside Fusion**, not in the project venv.
Fusion ships its own interpreter and `adsk.core` / `adsk.fusion` exist only
there -- these files will not import from `.venv`, and that is expected.

**Data stored here:** Python (in Fusion). Diffable, committed.

## Portals

| Portal | File | Type | Does | Run order |
|---|---|---|---|---|
| `handoff____` | [frame_params.json](frame_params.json) | JSON | Generated by `frame fusion -o`. Every script below reads it | 0 |
| `syncparams____` | [sync_params.py](sync_params.py) | Python (in Fusion) | JSON -> Fusion User Parameters. Idempotent | 1 |
| `holes____` | [hole_pattern.py](hole_pattern.py) | Python (in Fusion) | Bolt circles, square patterns, strap slots. Also a library | 2 |
| `nest____` | [nest_parts.py](nest_parts.py) | Python (in Fusion) | Shelf-pack the cut parts into the 250x250 sheet, report fit | 3 |
| `masscheck____` | [mass_check.py](mass_check.py) | Python (in Fusion) | Fusion's real volume x wood density vs `frame mass` | 4 |
| `exportdxf____` | [export_dxf.py](export_dxf.py) | Python (in Fusion) | `CUT_*` sketches -> `dxf/`. Refuses if validation fails | 5 |
| `common____` | [_common.py](_common.py) | Python (in Fusion) | Shared helpers. Leading underscore = not a runnable script | -- |

**Never run these against a design you have not saved.** They are written to be
idempotent, but Fusion has no undo across a script boundary.

They are exercised by [`tests/test_fusion_scripts.py`](../tests/test_fusion_scripts.py)
against a fake `adsk`, which catches missing payload keys, broken format strings
and unit slips -- but not whether Fusion behaves as assumed. Treat the first run
in Fusion as a real test.

## Two conventions the scripts rely on

| Name starts with | Means |
|---|---|
| `CUT_` | A sketch or body that is a real part cut from the sheet |
| `REFERENCE_` | Construction geometry the scripts drew. Delete before exporting |

`export_dxf` and `nest_parts` find your parts by that prefix and ignore
everything else, so naming a sketch `CUT_center_plate` is what makes it a part.

## Units

**Every length in the Fusion API is centimetres**, whatever the document shows.
`_common.mm()` and `_common.to_mm()` convert. A silent factor-of-ten error is
the single most common way to lose an afternoon here.

## Install

```powershell
.\install-fusion-scripts.ps1        # from the repo root; -WhatIf to preview
```

Fusion only lists scripts under its own `API\Scripts` folder, one folder each
with a `.manifest`. Rather than copy these files there -- which forks them, so
you edit one copy and run the other -- the installer writes a **shim** per
script that puts this folder on `sys.path` and calls the real module.

Two things follow:

- git stays the single source of truth; the shims hold no logic
- editing a file here and re-running it in Fusion picks the change up
  immediately. The shim reloads the module. No Fusion restart

They appear in Fusion as `frame_sync_params`, `frame_hole_pattern`, and so on:
Utilities -> **ADD-INS** (`Shift+S`) -> Scripts tab. Re-run the installer after
adding a new script here; `-Uninstall` removes them.

Then, every time a number in `params.yaml` changes:

```powershell
frame fusion -o          # rewrites frame_params.json in this folder
```

and re-run `sync_params` inside Fusion. The scripts never recompute geometry --
if `frame_params.json` is stale, the model is stale, and nothing will warn you.

## MCP vs scripts

Both drive Fusion. Use each for what it is good at:

| | Fusion MCP | Scripts here |
|---|---|---|
| Good for | Exploring, one-off changes, "make it look like this" | Repeatable steps you have already proven |
| Repeatable | no | yes |
| In git | no | yes |

Explore with MCP. When something works, **lock it in as a script here** so the
next frame does not need the conversation again.

## Getting data in

`frame fusion` prints resolved parameters as JSON. That is the handoff -- these
scripts read it rather than recomputing anything. Geometry is solved once, in
[`src/frame_tools/geometry.py`](../src/frame_tools/geometry.py).

# photos/own/

**Purpose:** Your own photographs of the actual salvaged hardware. Ground truth
about *your* parts -- trustworthy in a way downloaded images are not.

**Data stored here:** Raster (`.jpg`, `.png`). Downscale to ~1500px before
committing.

## Portals

| Portal | Pattern | Type | Holds |
|---|---|---|---|
| `motorpic____` | `motor_*.jpg` | Raster | Bolt pattern, base diameter, ruler in frame |
| `fcpic____` | `fc_*.jpg` | Raster | Top (mounting holes) and bottom (solder pads) |
| `battpic____` | `battery_*.jpg` | Raster | Dimensions and connector |
| `woodpic____` | `wood_*.jpg` | Raster | Grain direction of your stock |
| `buildpic____` | `assembly_*.jpg` | Raster | Progress shots, linked from the build log |

## The one rule

**Put a ruler or caliper in frame.** A photo without scale cannot answer a
dimension question three weeks later, which is the only reason these exist.

Link from [`docs/measurements.md`](../../docs/measurements.md) and
[`docs/build-log.md`](../../docs/build-log.md).

Downloaded images belong in [`../reference/`](../reference/README.md), never here.

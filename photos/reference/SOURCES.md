# Reference image sources

Every file in this folder gets a row. No row, no trust.

| File | Source URL | Retrieved | Note |
|---|---|---|---|
| _(example)_ `betaflight_pinout.png` | `https://...` | 2026-08-24 | Verify it matches YOUR board revision |

## Why

- **Attribution** -- these are someone else's images.
- **Verification** -- a pinout for a similar-but-different board will let out
  the magic smoke. The URL is how you re-check the match.
